## About

The Input OTP is built on top of [`input-otp`](https://input-otp.rodz.dev/), which is created by [@guilherme_rodz](https://x.com/guilherme_rodz).

## Installation

<Installation>
<div>
```bash title="Terminal"
npx shadcn@latest add https://9ui.dev/r/input-otp.json
```
</div>
</Installation>

## Usage

```tsx title="Imports"
import {
	InputOTP,
	InputOTPGroup,
	InputOTPSeparator,
	InputOTPSlot,
} from "@/components/ui/input-otp"
```

```tsx title="Anatomy"
<InputOTP>
	<InputOTPGroup>
		<InputOTPSlot />
	</InputOTPGroup>
	<InputOTPSeparator />
</InputOTP>
```
